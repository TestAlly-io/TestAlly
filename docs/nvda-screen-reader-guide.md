# NVDA Screen Reader Guide

## What is NVDA?

**NVDA** (NonVisual Desktop Access) is a free, open-source screen reader for Microsoft Windows. It is one of the most widely used assistive technologies for blind and visually impaired users worldwide.

NVDA was developed by NV Access, an Australian non-profit organization, and has been continuously maintained since 2006. It provides an alternative to commercial screen readers like JAWS, making screen reading technology accessible to everyone at no cost.

## What Does NVDA Do?

NVDA converts on-screen content into synthesized speech or Braille output (when connected to a Braille display), allowing users to navigate and interact with their computer without relying on visual feedback. Key capabilities include:

- **Reading Text**: Announces text, buttons, links, form fields, and other UI elements
- **Web Browsing**: Interprets semantic HTML, ARIA landmarks, headings, and page structure
- **Application Support**: Works with most Windows applications, including Microsoft Office, web browsers, and development tools
- **Keyboard Navigation**: Enables complete system control via keyboard shortcuts
- **Braille Support**: Compatible with 70+ Braille displays
- **Multilingual**: Supports 50+ languages with multiple speech synthesizers

## Why Use NVDA for Accessibility Testing?

For developers and QA testers working on web accessibility:

1. **Zero Cost**: Free to download and use, no license required
2. **Industry Standard**: Second most popular screen reader after JAWS (per WebAIM surveys)
3. **Web Standards Compliance**: Excellent support for WCAG-compliant markup
4. **Active Development**: Frequent updates and strong community support
5. **Realistic Testing**: Experience how actual users navigate your applications

## Download Instructions

### Step 1: Visit the Official Website

Navigate to the official NVDA download page:

**URL**: [https://www.nvaccess.org/download/](https://www.nvaccess.org/download/)

### Step 2: Choose Your Download Option

You'll see two primary download options:

1. **Download NVDA** (recommended) — Latest stable release
2. **Donate and Download** (optional) — Support development while downloading

For testing purposes, the free download is sufficient.

### Step 3: Get the Installer

Click the **"Download"** button to download the NVDA installer:

- **File Name**: `nvda_[version].exe` (e.g., `nvda_2024.1.exe`)
- **File Size**: Approximately 110-130 MB
- **Source**: Downloaded directly from NV Access servers

> **Note**: Always download from the official nvaccess.org website to ensure you receive legitimate, malware-free software.

## Installation Instructions

### Before You Begin

- **Close unnecessary applications** to avoid interruptions
- Ensure you have **administrator privileges** on your Windows machine
- Have speakers or headphones ready to hear audio feedback

### Installation Steps

#### 1. Run the Installer

Locate the downloaded `nvda_[version].exe` file (typically in your **Downloads** folder) and double-click to launch it.

#### 2. License Agreement

The NVDA License Agreement window will appear:

- Read the GNU General Public License v2
- Click **"I agree"** to proceed

**IMPORTANT**: NVDA speech will begin automatically when the installer launches. You'll hear:
> "NVDA is loading, please wait..."

#### 3. Choose Usage Mode

You'll be presented with three options:

| Option | Description | Use Case |
|--------|-------------|----------|
| **Install NVDA on this computer** | Permanent installation with desktop shortcut | Recommended for regular testing |
| **Create portable copy** | Run from USB or folder without installation | Useful for testing on multiple machines |
| **Continue running temporary copy** | Run once without installing | Quick testing, won't persist after reboot |

**For accessibility testing**, select **"Install NVDA on this computer"** and click **Continue**.

#### 4. Installation Options

Configure the following settings:

- ☑ **Create Desktop Shortcut** (recommended)
- ☑ **Copy Portable Configuration to Current User Account** (if upgrading)
- **Start NVDA after installation** (optional, usually checked by default)

Click **Continue** to proceed.

#### 5. Complete Installation

- The installer will extract files and configure NVDA
- Progress bar will indicate installation status
- Total installation time: approximately 30-60 seconds

When complete, you'll see:
> "Installation successful"

Click **OK** or press **Enter** to finish.

#### 6. First Launch Welcome Dialog

If you selected "Start NVDA after installation," the **Welcome Dialog** appears:

- **Keyboard Layout**: Choose `Desktop` or `Laptop` layout (affects modifier keys)
- **Use Caps Lock as NVDA Modifier Key**: Recommended for easier access
- ☑ **Start NVDA after I sign in to Windows** (optional — enable for persistent testing environment)

Click **OK** to complete setup.

## Verifying Installation

### Confirmation Checklist

✅ **Audio Feedback**: You should hear NVDA speak when hovering over or tabbing to UI elements  
✅ **System Tray Icon**: Look for the NVDA icon (blue/green speech bubble) in the Windows system tray  
✅ **Desktop Shortcut**: An NVDA shortcut should appear on your desktop (if selected)

### Test NVDA Functionality

1. Press `Insert + T` (or `CapsLock + T`) — NVDA should announce the current window title
2. Press `Insert + Down Arrow` — NVDA should start reading all content from the current position
3. Open a web browser and press `H` — NVDA should jump to the next heading

If all tests pass, NVDA is successfully installed.

## Basic Usage

### Essential Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Insert` or `CapsLock` | NVDA modifier key (based on your configuration) |
| `NVDA + Q` | Quit NVDA |
| `NVDA + N` | Open NVDA menu |
| `NVDA + T` | Read window title |
| `NVDA + Down Arrow` | Read from current position (say all) |
| `NVDA + S` | Toggle speech mode (on/off/beeps) |
| `Tab` | Navigate to next interactive element |
| `Shift + Tab` | Navigate to previous interactive element |

### Web Browsing Commands

| Key | Action |
|-----|--------|
| `H` / `Shift + H` | Next/Previous heading |
| `1-6` / `Shift + 1-6` | Next/Previous heading at level 1-6 |
| `K` / `Shift + K` | Next/Previous link |
| `D` / `Shift + D` | Next/Previous landmark |
| `F` / `Shift + F` | Next/Previous form field |
| `B` / `Shift + B` | Next/Previous button |
| `T` / `Shift + T` | Next/Previous table |

### Forms Mode

NVDA automatically enters **Forms Mode** when focused on form fields:
- Type normally in input fields
- Press `Escape` to exit forms mode and return to browse mode

## Recommended Browser for Testing

**Firefox** and **Google Chrome** have the best NVDA compatibility:

- Firefox: Native accessibility API support (recommended)
- Chrome: Good ARIA and landmark support
- Edge: Built on Chromium, similar to Chrome

Install Firefox from [https://www.mozilla.org/firefox/](https://www.mozilla.org/firefox/) for optimal NVDA testing.

## Uninstallation (If Needed)

To remove NVDA from your system:

1. Open **Settings** → **Apps** → **Installed apps**
2. Search for **"NVDA"**
3. Click the three-dot menu → **Uninstall**
4. Follow the uninstallation wizard
5. Restart your computer (optional but recommended)
